835. « If there is an active German within 2
hexes, give a Turn to the German with the
fewest Turns. If 2 or more eligible Germans
have the same number of Turns, give one to
the soldier closer to an active US soldier (then
to the one with the higher WS, if still tied). If
all eligible Germans have 2 Turns, see 801.

© If no other active Germans are within 2
hexes, conduct 801.

836. © If out of US sight, remove the German
from the map.

© If in US sight and in open terrain, move as
quickly as possible. Fall prone after move if
free stance change is available.

¢ If in US sight and not in open terrain,
crouch and conduct best fire. Fall prone after
fire if free stance change is available.

839. © If there is an active US soldier in the
hex, assault to kill.

° If there is no active target in the hex,

860. © If German occupies a building, stand
and conduct snap fire at as many targets as
possible, beginning with the closest and then
the easiest. Fall prone if free stance change is
available.

© If German does not occupy a building,
crouch and conduct snap fire at as many
targets as possible, beginning with the closest
and then the easiest.

861. © If there is an active German in the
same or adjacent hex, crouch and give a Turn
to the German with the fewest Turns. If there
are 2 or more eligible Germans with the same
number of Turns, give to the soldier with the
higher WS. If all eligible Germans have 2
Turns, see 856.

* If there are no other active Germans in the
same or adjacent hexes, see 856.

862. « If there is no active target in sight,
move as quickly as possible. Fall prone if an
active target is in sight and free stance change
is available.

© If there is an active target in sight and
soldier occupies an open hex, move as quickly
as possible. Fall prone after movement
(spending a Movement Point to do so, if
necessary).

© If there is an active target in sight and
soldier occupies a non-open hex, crouch and
conduct best fire at easiest target.

863. « If there is no active target in sight,
move as quickly as possible. Fall prone if
there is an active target in sight and free
stance change is available.

© If there is an active target in sight and
soldier occupies an open hex, move as quickly
as possible. Fall prone in first non-open hex
entered (spending a Movement Point to do so,
if necessary). If no non-open hex is entered,
fall prone in last hex entered (again, spending
an MP, if necessary).

© If there is an active target in sight and
soldier occupies a non-open hex, conduct 869.

864. © If there is no active target in sight,
move as quickly as possible. Fall prone if
there is an active target in sight and free
stance change is available.

© If there is an active target in sight, stand
and conduct one snap fire. Then move as
quickly as possible, spending up to half the
soldier's MPA (rounded down). Fall prone if
free stance change is available.

© If there are 1 or 2 active targets in sight,

866. © If there is no active target in sight,
move as quickly as possible. Fall prone if an

© If there are 1 or 2 active targets in sight,

868. Move as fast as possible. Fall prone at

869. © If an active US soldier is in the same
hex, assault to kill.

© If grenade unavailable or target at greater
than 4-hex range, conduct 801.
